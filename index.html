Hướng dẫn setup
  1. Upload DS_DiemDanh.xlsx lên Google Drive
  2. Chuột phải → Mở bằng Google Trang tính (chuyển thành Google Sheet)
  3. Copy Sheet ID từ URL
  4. Vào Extensions → Apps Script, dán code Code.gs
  5. Sửa SHEET_ID → Deploy → Web App → Anyone
  6. Copy URL → dán vào ô trên → bấm Kiểm tra kết nối
